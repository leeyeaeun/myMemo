# Memo

> I just wanted a simple notes app—ad-free, uncluttered, beautiful, and refined.

로컬 전용 미니멀 메모 앱

## 실행

콘솔 창 없이 실행하려면 **`Memo.vbs`**를 더블 클릭합니다. 이 파일의 바로가기를 바탕화면에 두어도 됩니다.

`run.bat`도 앱을 별도 프로세스로 실행한 뒤 바로 닫히도록 구성되어 있습니다.

## 스티키 메모

- 왼쪽 메모 목록을 더블 클릭하거나 상단의 `▣` 버튼을 누르면 독립 메모 창이 열립니다.
- 메모 목록을 우클릭하거나 스티키 상단의 `⌫` 버튼으로 메모를 삭제할 수 있습니다.
- 왼쪽 메모 카드를 위아래로 드래그하면 순서를 바꿀 수 있고, 변경한 순서는 자동 저장됩니다.
- 상단 영역을 드래그해 원하는 위치로 옮길 수 있습니다.
- 메모의 네 변이나 네 모서리 주변의 넓은 영역을 드래그해 원하는 크기로 바꿀 수 있습니다. 오른쪽 아래의 큰 손잡이도 사용할 수 있습니다.
- `PIN`은 해당 메모를 항상 위에 고정합니다.
- 전체 메모 창을 닫아도 핀으로 고정한 스티키 메모는 계속 유지됩니다.
- 스티키 상단의 `☰` 버튼으로 전체 메모 관리 창을 다시 열 수 있습니다.
- 글자 크기·목록·굵게·기울임·밑줄·취소선·정렬·이미지 도구는 스티키 상단 바에 항상 표시됩니다.
- 클립보드에 복사한 이미지는 메모에서 `Ctrl+V`로 현재 커서 위치에 바로 넣을 수 있습니다.
- `Ctrl+B`, `Ctrl+I`, `Ctrl+U`로 굵게·기울임·밑줄을 적용할 수 있습니다.
- `Ctrl+Shift+X`로 취소선을 적용하거나 해제할 수 있습니다.
- `Ctrl+Shift+>`·`Ctrl+Shift+<` 또는 `Ctrl+]`·`Ctrl+[`로 글자 크기를 조절할 수 있습니다.
- 위치, 크기, 열린 상태는 종료 후에도 기억됩니다.

## 색상과 테마

- 편집 화면의 색상 버튼에서 프리셋 또는 직접 색상을 고를 수 있습니다.
- 우측 상단 `•••` → **전체 메모 테마**에서 모든 메모의 색 조합을 한 번에 바꿀 수 있습니다.

## 저장과 백업

메모는 `%LOCALAPPDATA%\Memo\notes.json`에 자동 저장됩니다. 이전 Morrow Notes 데이터가 있으면 첫 실행 시 자동으로 가져옵니다. 이미지도 문서 안에 포함되며 `•••` 메뉴에서 전체 백업과 복원이 가능합니다.
